# Открытые вопросы: требуют решения до реализации

> Рабочий документ. Сюда попадают нерешённые вопросы из spec.md §8,
> предложения architecture.md с пометкой `[предложение]` и пробелы, найденные
> при планировании. По каждому вопросу: контекст, варианты, рекомендация и
> поле **Ответ:** для решения.
>
> После ответа вопрос оформляется как ADR в `docs/decisions/`, удаляется
> отсюда и из spec.md §8, а документы правятся под принятое решение.
